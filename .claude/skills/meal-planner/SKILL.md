# Skill: Meal Planner

Build a practical meal plan for a clean bulk. Target: 145 → 175 lbs.

## When to use
- Weekly meal planning
- Need new food ideas or variety
- Generating a grocery list

## Context
- Goal: gain ~30 lbs of lean mass, no junk bulk
- Calorie target: ~3,200–3,500 kcal/day
- Protein target: ~175g/day (1g per lb of goal bodyweight)
- Approach: real food, affordable, practical for someone working restaurant shifts

## Workflow

**Step 1 — Check in**
Ask:
- Any foods to avoid or things already in the fridge?
- How much time to cook this week? (quick meals vs. full meal prep)
- Any budget limit?

**Step 2 — Build the plan**
Generate a 7-day plan with:
- Breakfast, lunch, dinner, 1–2 snacks per day
- Hit calorie and protein targets daily
- Variety across the week — don't repeat the same meal back to back
- Practical meals, not chef-level complexity

**Step 3 — Grocery list**
Consolidated list organized by section:
- Proteins
- Produce
- Carbs / grains
- Dairy / fats
- Pantry / misc

**Step 4 — Save**
Write the full plan to `references/meal-plans/YYYY-MM-DD.md`.

## Output Format
Weekly plan first, grocery list at the bottom. Scannable — no essays.
